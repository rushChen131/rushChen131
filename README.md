### 代表项目

**[PersonalOS](https://github.com/rushChen131/personalOS)** · 个人生活操作系统
日记是唯一需要手写的输入，`JournalCreated` 事件扇出到向量化与记忆蒸馏；聊天 Agent 只能通过带权限校验的工具访问数据。同一套代码支持本地 SQLite（零依赖启动）与 PostgreSQL + pgvector / Redis / MinIO 全栈部署。
